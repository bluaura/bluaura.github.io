어닝의 진짜 포인트 3가지

① Azure 재가속 — 규모가 커지는데 성장률이 오른다. FY26 Q4 43%, FY27 Q1 48%, Q2 가이던스 49~50%. Microsoft Cloud도 30%로 가속했고(직전 27%), 분기 순증 달러는 전년의 거의 2배다. 다만 동인이 신규 증설이 아니라 GPU·CPU 함대의 효율 개선과 토큰 단가 상승이라는 점이 핵심이다.

② 좌석 과금에서 좌석+사용량 과금으로. 세그먼트를 Agents and Infra($76.8B, +25%)와 Devices and Consumer($15.5B, −3%)로 개편했다. M365 Commercial Cloud(+18%, 조정 기준)는 GitHub Copilot 사용량 과금이 끌었고, E3·단품 SKU는 회사가 직접 영업 실행 부진을 인정했다. 유료 좌석 성장은 +5%로, 성장은 ARPU가 주도했다.

③ 선행지표 — RPO $677B, 12개월 내 인식분 +29%. 전체 RPO 성장률은 84%에서 73%로 둔화했지만 전년 OpenAI 대형 약정의 기저 효과다. 상업 bookings −12%도 같은 이유다. 12개월 이후 인식분은 +98%로 장기 계약 비중이 커지고 있다.

마진·현금흐름 품질

  • FCF 서프라이즈는 타이밍이다. 3P(제3자) GPU 용량 인도가 하반기로 밀리며 capex가 $5B 이상 덜 나갔다. 하반기 capex가 가속하면 반납된다.
  • 감가상각 압박: capex의 약 3/4이 GPU·CPU 같은 단수명 자산이다. Q2 COGS 가이던스(+26~27%)가 매출 가이던스(+18~19%)보다 빠르고, MS Cloud 매출총이익률은 66%에서 약 65%로 낮아질 전망이다.
  • Rule of 40: 매출 성장 19 + FCF 마진 20 = 39로 경계선.
  • OCF $58B(+29%)가 순이익 $36.6B를 크게 상회해 현금 품질은 양호하다. GAAP EPS는 미확인.

2. 어닝콜 분석 리뷰

경영진 메시지

Satya Nadella (CEO) — Copilot을 "업무의 새 OS"로 규정했다. 직전 분기 'super app'에서 한 단계 격상한 표현으로, Dynamics 365·GitHub·에이전트가 그 위에 올라가는 플랫폼이라는 주장이다. 또 소수 고객이 대량 용량을 사들여 몇 분기 성장을 만드는 것은 사업이 아니라고 선을 그었다. 콜에서 애널리스트가 언급한 OpenAI 매출 비중 11%에 대한 장기 헤지 신호로 읽힌다.

Amy Hood (CFO) — 수요가 여전히 공급을 초과한다. Q2 Azure 가이던스는 Q1 효율 개선의 연장에 더해 추가 효율 확보를 전제로 한다. 캘린더 2026년 capex 약 $170B, FY27 FCF 흑자 유지, 리스 외에 부채 시장 조달도 열어뒀다.

이 콜에서 얻은 다른 종목 정보

  • 메모리: capex 설명에서 메모리·스토리지 단가 상승을 직접 언급했다. SK하이닉스·삼성전자·마이크론에 긍정적이다.
  • GPU·CPU: GB300이 대형 리전 GPU 배포의 다수, NVIDIA Vera Rubin 첫 도입. CPU 수익화 강조와 자체 Cobalt CPU는 서버 CPU 수요(AMD·Arm)에 긍정적이다.
  • 네오클라우드: 3P GPU-as-a-Service 계약이 하반기로 지연됐다. CoreWeave·Nebius 등 인도 실행 리스크다.
  • PC OEM: Windows OEM −27%, 재고가 높고 Q2는 30%대 중반 감소 가이던스. HP·Dell·Lenovo·LG전자 PC 부문과 인텔 클라이언트 부문에 부정적이다. 한편 MS는 RTX Spark 기반 AI PC와 로컬 에이전트를 Windows 차기 성장축으로 제시했다.
  • AWS 프리뷰: 수요가 공급을 초과하는 업황은 아마존에도 우호적이다. 같은 날 발표한 Alphabet은 상대적으로 부진한 반응을 받았다.
  • 개발 생태계: GitHub PR의 1/3 이상을 에이전트가 생성한다(6개월간 6배). 코딩 에이전트들이 MS 거버넌스 레이어(MXC) 위로 수렴하고 있다.

정리

판정 — 서프라이즈와 가이던스 상향. 숫자는 깨끗하지만 Azure 가속의 원천(효율·단가)은 반복성이 낮다. 보유는 유지, 신규 진입은 전고점 직하라 분할이 합리적이다.

Thesis-breaker — 다음 중 하나라도 발생하면 투자 논리 재검토
  • FY27 Q2 Azure cc 성장률 47% 미만
  • M365 Commercial Cloud 성장률 18% 미만 (연중 가속 약속 위반)
  • MS Cloud 매출총이익률 63% 미만 또는 FY27 FCF 흑자 가이던스 철회
  • Q2 콜에서도 Copilot 좌석 수 비공개이면서 M365 유료 좌석 성장률 5% 미만
  • RPO 12개월 내 인식분 성장률 20% 미만

단기 관전 포인트 (1~2주) — 전고점 $555 돌파 여부, 애널리스트 추가 상향, AWS 실적의 클라우드 성장률, 부채 발행 공시.

중기 관전 포인트 (1~2분기) — Q2 Azure 49~50% 달성(효율 의존), Copilot 좌석 수 재공개 여부, 3P GPU 인도 정상화, OpenAI 매출 비중, 매출총이익률 65% 방어.

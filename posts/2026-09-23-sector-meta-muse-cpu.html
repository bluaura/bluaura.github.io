Meta Muse가 CPU 주가를 끌어올린 이유는 사용자마다 클라우드에 전용 가상 컴퓨터(VM) 한 대씩을 붙여주는 구조이기 때문이다. 챗봇은 GPU만 잠깐 쓰고 끝나지만, 에이전트는 GPU(추론) 외에 브라우저 실행·도구 호출·코드 실행·상태 유지를 CPU가 계속 떠맡는다. 월가는 이를 "소비자 에이전트 시대의 첫 대중 흥행"으로 해석한다. 다만 Muse가 실제로 CPU를 얼마나 쓰는지는 공개되지 않아, 기대가 먼저 반영된 부분이 있다.

2. 사용자는 무엇을 좋아하고, 무엇이 부족한가

  • 호평 — 먼저 말을 거는 능동형 비서(아침 뉴스레터, 목표 추적), 에이전트의 작업 단계를 보여주는 활동 피드와 권한 모델, 캐릭터 아바타. "지금까지 써본 개인 에이전트 중 UX 최고"라는 평가(Lenny's Newsletter). WhatsApp·인스타그램 안에 있어 별도 앱 채택 장벽이 낮다.
  • 한계 — 브라우저 쇼핑 성공률이 들쭉날쭉하다(신발 구매 실패, 영화표 예매 성공). "완성도는 좋은데 Meta에 데이터를 맡기기 싫다"는 신뢰 문제가 반복적으로 제기된다.
  • 플랫폼 충돌 — 9월 20일 Amazon이 Muse의 자사 쇼핑 접근을 차단했다(ZeroHedge). Meta는 Shopify 제휴로 대응했다.
삶의 변화 관점 — "검색 → 비교 → 직접 클릭"하던 일을 "시키고 → 승인만" 하는 방식으로 바꾸는 첫 대중 제품이다. 현재 주 용도는 쇼핑 조사, 예약, 일정·메일 정리다.

3. 월가는 일시적 유행이 아니라고 보는가

부분적으로 그렇다. "구조적 흐름"과 "Muse 개별 성공"은 구분해서 봐야 한다.

월가가 확신하는 것은 "에이전트가 CPU 수요를 구조적으로 늘린다"는 흐름이다. Bernstein(6월)과 Morgan Stanley가 Muse 이전부터 같은 주장을 해 왔다. Muse는 이를 소비자 시장에서 처음 입증한 촉매이고, Muse 자체의 장기 흥행은 아직 검증 전이다.

4. 6개월~1년 뒤: 경쟁 서비스가 쏟아질까

이미 경쟁이 시작됐다. Muse는 "시초"라기보다 "첫 대중 흥행작"이다. Axios는 "소비자 에이전트 경쟁이 하룻밤 새 터졌다"고 표현했다.

5. 왜 CPU인가 — 기술적 연관 관계

챗봇: 질문 → GPU 추론 → 답변 → 종료 (짧고 간헐적)
에이전트: 사용자 1명 = 상시 가동 VM 1대
· GPU — 모델 추론(계획·판단)
· CPU — VM 가상화, 헤드리스 브라우저, 폼 입력, API·도구 호출, Python 코드 실행 샌드박스, 오케스트레이션, 장기 상태·컨텍스트 관리
→ 앱을 닫아도 계속 돌아가므로 CPU 점유 시간이 크게 늘어난다
  • 비율 변화 — 기존 AI 서버는 GPU 8개당 CPU 1~2개, GB200·Vera Rubin 세대는 2:1, 에이전트 시대에는 1:1 이상으로 이동(Bernstein, Morgan Stanley).
  • 공급 부족 — Intel CEO Lip-Bu Tan은 "고객 수요의 50%만 공급 가능"하다고 밝혔다(24/7 Wall St.).
  • 시장 전망(2030 서버 CPU) — Bernstein 기본 $137B(상향 $223B), Arm $120B, AMD $220B, Morgan Stanley는 에이전트로 $32.5~60B 추가.
  • 주가(9/21) — Arm +13~17%, Intel +12%, AMD +9.95%. SOXX는 +3%에 그쳐 CPU에 집중된 랠리였다.
주의 — Muse가 CPU를 얼마나, 누구의 칩으로 쓰는지는 공개되지 않았다. 애널리스트 추정도 GPU 1개당 CPU 4~40개로 편차가 10배다. 같은 날 미·중 정상 만찬 기대, SK하이닉스-Intel 협력설 등 다른 호재도 겹쳤다(Implicator).

7. AI 섹터가 다시 관심을 받는가

그렇다. "AI 속도조절론"을 뒤집을 근거가 생겼다. 설비투자 회의론의 핵심은 "돈 버는 소비자 킬러앱이 없다"였는데, Muse가 대중이 실제로 쓰는 에이전트를 처음 보여줬다. 수요의 성격도 학습(일회성·집중형)에서 추론·에이전트(사용자 수에 비례하는 상시형)로 옮겨가고 있다.

에이전트 시대의 인프라 수요는 CPU만의 이야기가 아니다. CPU가 가장 먼저 반응했지만, 사용자 수에 비례해 상시로 쌓이는 수요의 최종 수혜는 메모리·스토리지까지 넓게 퍼진다. 밸류에이션 측면에서는 이미 급등한 CPU보다 메모리 쪽의 부담이 더 작다.
이 글은 개인적인 학습과 기록을 위한 것이며, 특정 종목의 매수·매도를 권유하지 않습니다. 일정과 수치는 발표 시점에 변경될 수 있으므로 반드시 원문을 확인하시기 바랍니다. 투자 판단과 그 결과에 대한 책임은 투자자 본인에게 있습니다.

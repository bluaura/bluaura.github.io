트렌드 종합

이번 주 흐름은 세 가지로 요약된다. 첫째, 상위 모델급 성능이 $2/$10 가격대로 내려왔다. Sonnet 5.5와 GPT-6.1 Sol이 같은 가격표를 들고 나오면서 비용 대비 성능 경쟁이 본격화됐다. 둘째, 경쟁 무대가 챗봇에서 에이전트로 옮겨갔다. Meta Muse, Microsoft Copilot, OpenAI Agents API가 모두 '대신 실행하는 AI'를 내세웠고, 투자금도 Instinct, Ema, Reco 같은 에이전트·에이전트 보안 기업에 몰렸다. 셋째, 자본과 규제가 함께 커지고 있다. OpenAI의 $1.4T 밸류에이션과 AMD–World Labs 인수가 나온 한편, 백악관 안전 협약·UN 안보리·EU 사고 보고 논의가 같은 주에 겹쳤다.

개발자 관점 시사점

  • 모델 비용 재산정: 기존에 Opus/Astra급을 쓰던 워크로드를 Sonnet 5.5나 GPT-6.1 Sol로 옮겼을 때의 품질을 A/B 테스트해 볼 시점이다. 두 모델 모두 캐시 입력 단가가 크게 낮으므로 prompt caching 구조를 먼저 점검하자.
  • 에이전트 API 표준화: OpenAI Agents API(computer-use·멀티 에이전트)와 Decisions API가 나오면서 직접 만든 오케스트레이션을 공식 API로 바꿀 수 있는지 검토할 만하다. 저가 분류·라우팅 모델(Luna, Solar Decide)을 앞단에 두면 비용을 줄일 수 있다.
  • 코딩 에이전트 도구: Sonnet 5.5는 GitHub Copilot에 바로 들어왔고, Codex에는 클라우드 환경과 PR 리뷰 기능이 생겼다. 팀 CI와 리뷰 흐름에 붙여볼 수 있다.
  • 오픈 웨이트·온디바이스: Solar Mini 4(활성 3B), FLUX 3 Action(7B)처럼 작은 고성능 모델이 늘고 있다. 모바일·엣지 추론에서 라이선스 조건(상용 가능 여부)을 먼저 확인하자.
  • 보안·컴플라이언스: 에이전트가 외부 시스템에 접근하는 사고가 잇따르고 있다. 샌드박스와 네트워크 격리, 권한 최소화, 에이전트 인벤토리 관리를 기본 설계에 넣어야 한다. EU 사용자를 대상으로 하는 서비스라면 AI Act 투명성 의무도 체크해야 한다.

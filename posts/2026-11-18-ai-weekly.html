모델 출시·업데이트 (5건)

1. OpenAI, GPT-6.2 Astra·Sol 출시

고난도 작업용 Astra와 일상 업무용 Sol을 동시 공개하고 ChatGPT와 API에 바로 배포했다. OpenAI 자체 발표 기준으로 Astra는 Agents' Last Exam에서 Claude Fable 5.2보다 5.5포인트 앞섰고, 표준 API 토큰 가격을 20% 내렸다. Sol은 GPT-6.1 Sol과 같은 가격을 유지한다. 벤치마크 수치는 모두 자체 보고 값이다.

IBTimes · OpenAI · 2026-11-17

2. Google, Gemini 4 Hydrogen 정식 출시

일상 코딩과 에이전트 실행용 고속 모델이다. Gemini 앱, Google Search, AI Studio, Gemini API에 순차 적용된다. 컨텍스트는 약 1M 토큰이고, API 가격은 $1.50/$7.50 per 1M tokens이다. 상위 모델 Gemini 4 Carbon($2/$10)은 11/10 GA됐다.

Google Blog · PromptZone · 2026-11-12

3. Alibaba, Qwen4-Max 정식 출시

1M 컨텍스트에 입력 $1.50, 출력 $4.50 per 1M tokens이다. 에이전트 작업에서 프런티어급에 근접한 성능을 낮은 가격에 제공하는 것이 목표다. 11/11 Preview 공개 뒤 닷새 만에 정식 버전이 나왔다.

LLM Stats · 2026-11-16

4. Tencent, 초저가 Hy4 flash 공개

트렌드 종합

이번 주는 프런티어 모델 경쟁이 '성능'보다 '가격'으로 옮겨 간 한 주였다. OpenAI가 Astra 단가를 낮췄고, Google Hydrogen·Alibaba Qwen4-Max·Tencent Hy4 flash·Microsoft MAI 모델이 모두 가격 대비 성능을 전면에 내세웠다. 분류·판정 전용 모델(Gemini Decision, Microsoft Decision 1.1, Perplexity Decider)이 동시에 등장한 것도 눈에 띈다. 에이전트가 수행하는 대량의 작은 호출을 싸게 처리하려는 수요 때문이다. 반면 에이전트 안전성은 소송과 외부 감사의 대상이 됐고, 반도체 공급망은 CEO 리스크와 수출통제라는 지정학 변수에 크게 흔들렸다. Anthropic 상장은 AI 밸류에이션이 공개시장에서 처음으로 본격 검증받는 이벤트다.

개발자 관점 시사점

  • 모델 티어 재점검: Hydrogen($1.50/$7.50), Qwen4-Max($1.50/$4.50), Hy4 flash($0.07/$0.281) 사이 단가 차이가 수십 배에 이른다. 라우팅·분류처럼 반복되는 호출은 Decision 계열 경량 모델로 분리하는 설계를 검토할 만하다.
  • Flutter 네이티브 연동: FFIgen·JNIgen stable로 BLE·Wi-Fi 등 플랫폼 API를 platform channel 없이 직접 호출할 수 있게 됐다. 기존 플러그인을 얇은 바인딩으로 대체할 수 있는지 확인하고, 내장 Material·Cupertino deprecation은 dart fix로 미리 대비하자.
  • MCP·에이전트 거버넌스: Microsoft는 Entra Agent ID로 MCP 서버·스킬을 통제하고, 로컬 에이전트를 컨테이너로 격리하는 방향을 제시했다. 기업 고객용 MCP 서버나 에이전트 툴을 만든다면 신원·권한·감사 로그 설계가 기본 요구사항이 된다.
  • 온디바이스 AI: Genkit Dart 1.0, MediaPipe Flutter 태스크, 국산 온디바이스 AI칩 로드맵이 함께 나오면서 모바일·가전 단의 로컬 추론 선택지가 늘고 있다.
  • 국내 규제 일정: AI 기본법은 과태료 계도기간이 최소 1년이라 당장 제재 부담은 적다. 다만 투명성·표시 의무 하위법령이 정비 중이므로 생성형 기능을 탑재한 앱은 표시 방식을 미리 설계해 두는 것이 안전하다.
